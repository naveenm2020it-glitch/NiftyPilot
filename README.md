# DayPilot (`com.naveenmanickam.daypilot`)

Offline-first daily planner, habit tracker, journal, and personal productivity suite built from scratch with Flutter & Dart.

## Build & Run Locally

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

The release APK will be output at:
`build/app/outputs/flutter-apk/app-release.apk`
